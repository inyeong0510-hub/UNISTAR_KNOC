## ■ 5. 개방 CSV 인코딩 UTF-8 통일

**쓸 재료**
- CSV 73개 중 **CP949 67 / UTF-8(BOM) 6**
- 직접 변환 검증: 73개 전부 UTF-8(BOM) 변환 후 문자열 동일 + 행·열 수 동일 → **73/73 통과** (`evidence/encoding_convert_20260919.md`)
- CP949는 맥·리눅스·분석도구에서 깨짐 / BOM 없는 UTF-8은 엑셀이 오독

**1) 현황** — 같은 기관·같은 포털인데 인코딩이 둘로 갈림(67/6)

▶

**2) 문제** — ①UTF-8 환경에서 깨짐 ②일괄 처리하려면 판별 로직 선행 ③비개발자는 여는 순간 포기

▶

**3) 제안** — UTF-8(BOM)로 통일. BOM을 넣는 이유(엑셀 호환)를 반드시 쓸 것. 기존 파일 일괄 변환 + 검증결과 공개

▶

**4) 기대효과** — **직접 해봤다는 점이 이 항목의 핵심.** 73/73 무손실 통과 = 실행 가능성 입증
