# 요소수 가격 대시보드 — 산출물 설명서

- 제작: 팀 유니스타 (Mission 1 · ④ 공공데이터 개선·활용 아이디어)
- 사용 데이터: 한국석유공사_주유소 요소수 평균판매가격(지역별), 동(상표별) — 공공데이터포털 개방자료
- 수록 기간: 2022.04.30 ~ 2026.06.30 (51개월)
- 산출물: 단일 HTML 파일 (첨부: 요소수_가격_대시보드.html). 인터넷 연결이나 로그인 없이 브라우저에서 바로 실행됨

## 1. 만든 이유

요소수는 경유 화물차 운행에 반드시 필요한 소모품이지만 휘발유·경유만큼 주목받지 않는다.
개방자료를 열어 확인한 결과 지역 간 가격 차이가 1.4배를 넘었으나, 이 사실을 한눈에 확인할 수 있는
수단은 없었다. 개방된 두 파일은 각각 51개월 × 17개 시도, 51개월 × 8개 상표의 표 형태여서
일반 이용자가 열어 비교하기 어렵다. 그래서 두 파일을 하나의 화면에서 비교할 수 있도록 직접 제작했다.

## 2. 기능

| 구성 | 내용 |
|---|---|
| 전국 평균 추이 | 51개월 선그래프. 1년 / 3년 / 전체 기간 전환 |
| 요약 타일 3종 | 최고가 지역, 최저가 지역, 최고−최저 격차 |
| 지역별 순위 | 17개 시도를 현재가 순으로 정렬, 막대로 상대 크기 표시 |
| 그래프 비교 | 순위 행을 누르면 해당 지역이 그래프에 추가됨(최대 2개) |
| 상표별 보기 | 8개 상표(SK에너지·GS칼텍스·HD현대오일뱅크·S-OIL·자영알뜰·EX알뜰·NH알뜰·자가상표) 동일 분석 |
| 원자료 보기 | 가공 없이 원본 수치를 표로 제공 |
| 접근성 | 각 선에 이름을 직접 표기하고 표 보기를 함께 제공하여 색만으로 구분하지 않도록 함 |

## 4. 화면 캡처

> 아래 두 자리에 실행 화면을 붙여 넣는다.

**① 지역별 화면** — 전국 평균 추이, 요약 타일, 지역 순위가 함께 보이는 전체 화면

　

**② 상표별 화면** — 좌측 두 번째 아이콘을 눌러 전환한 상태

　

## 5. 재현 방법

첨부한 `요소수_가격_대시보드.html` 파일을 브라우저에서 열면 된다.
데이터가 파일 안에 포함되어 있어 별도 설치나 인터넷 연결이 필요하지 않다.
수치는 개방 원자료를 가공하지 않고 그대로 사용했으며, 화면의 ‘표로 보기’에서 원자료를 확인할 수 있다.
