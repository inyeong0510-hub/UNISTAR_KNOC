## 3. 아이디어 후보 씨앗 (여기서 골라 발전시키기 — 목표 10개)

두 갈래로 낼 수 있다: **(가) 개선 아이디어** = 위 문제를 고치자, **(나) 활용 아이디어** = 이 데이터로 뭘 만들자.

### (가) 개선 아이디어 씨앗
1. 개방 CSV **인코딩을 UTF-8로 통일** — CP949 67개가 UTF-8 환경에서 한글 깨짐. 표준화 제안
2. 파일명 **NFC 정규화 규칙**을 개방 단계에 적용 — 크로스플랫폼 깨짐 방지
3. 자동차부탄 **제품코드 K015/K105 일원화** — API·가이드 간 코드 통일 및 변경이력 명시
4. API 가이드 **엔드포인트/항목명 표기 표준화** — 대소문자·언더스코어 불일치 제거
5. 중복·구버전 파일 정리 및 **최신본 표기 규칙** 제안

### (나) 활용 아이디어 씨앗
6. **지역별 유가 비교 대시보드** — 주유소 지역별/상표별 평균판매가 + 인천 제품별 가격
7. **LPG 가격 투명성 지도** — 충전소·판매소·집단공급 3계층 가격차 시각화
8. **알뜰주유소 실효성 분석** — 알뜰주유소 현황 + 형태별/상표별 가격차
9. **면세유·요소수 가격 모니터링** — 농어업 면세유, 요소수 상표별/지역별 추이
10. **에너지 전환 트래커** — 저공해차 보유·구매 + 온실가스 감축실적 + 지역별 충전소 개수
11. **세계 vs 국내 수급 비교** — 세계 매장량·생산량·소비 추이와 국내 수입·소비 연결
12. **정유사 공급가 → 소비자가 전달 지연 분석** — 주간 공급가격 vs 주유소 판매가 시차

> 12개 중 **10개로 압축 → 상위 3개를 깊게** 작성하는 걸 목표로.

## 4. 작성 틀 — 아이디어 1건당 (실적 제출 양식)

각 아이디어를 아래 4단으로 쓴다. **문장은 반드시 본인이 검증 후 직접 작성.**

```
■ 아이디어명:

1) 현황   — 지금 데이터/서비스가 어떤 상태인가 (숫자·근거 포함)
2) 문제   — 그래서 무엇이 불편/비효율/오류인가
3) 제안   — 구체적으로 무엇을 어떻게 바꾸/만들자
4) 기대효과 — 누구에게 어떤 가치가 생기나 (가능하면 정량)
```

**작성 팁**
- "현황·문제"는 위 2번 표의 수치·근거를 그대로 인용하면 설득력이 생긴다.
- 활용 아이디어는 "어떤 데이터셋 + 어떤 데이터셋"을 결합하는지 명시하면 구체적이 된다.
- AI에게는 *구조 잡기·후보 확장·표현 다듬기*까지만 맡기고, 최종 판단·문장은 본인이.
