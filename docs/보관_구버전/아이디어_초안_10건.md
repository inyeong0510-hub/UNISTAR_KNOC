### 1. 주유소 고유 식별자(ID)를 전 개방파일에 공통 부여

**현황**
일간 판매가격 파일(`과거_판매가격(주유소)`)에는 주유소마다 `A0033584` 형식의 고유 ID가 있다.
그런데 같은 기관의 다른 파일에는 이 ID가 없다.
- `알뜰주유소 현황` (1,328개) — 열이 상호·주소·상표·셀프여부뿐, ID 없음
- `인천지역 휘발유 가격 현황` (307개) — 상호명만 있음
- `인천지역 주유소 위치 현황` (322행, 고유 상호명 315개) — 상호명 + GIS 좌표, ID 없음

**문제**
ID가 없으니 파일을 합치려면 **상호명 문자열을 맞춰야 하는데, 이게 안 맞는다.**
- 인천 가격 307개 ↔ 인천 위치 315개 : 상호명 정확일치 **243개(79.2%)** — 64개가 좌표를 못 붙인다
- 알뜰 1,301개(중복 제외) ↔ 일간 가격 10,251개 : 정확일치 **1,197개(92.0%)** — 104개가 가격을 못 붙인다
같은 기관이 같은 주유소를 가리키면서 붙일 열쇠를 안 주는 것이다. 이용자는 매번 이름 맞추기
전처리를 새로 짜야 하고, 그 결과는 사람마다 달라진다.

**제안**
일간 판매가격 파일이 이미 쓰는 ID를 **기관 표준 키로 지정**하고, 주유소·충전소가 등장하는
모든 개방파일에 `주유소ID` 열을 하나 추가한다. 좌표·상표·알뜰여부처럼 잘 안 바뀌는 속성은
ID를 키로 하는 **기준정보(마스터) 파일 1개**로 따로 개방한다.

**기대효과**
열 하나 추가로 전처리 단계가 사라진다. 위 두 사례에서 유실되던 **64개·104개가 0개**가 되고,
누가 분석하든 같은 결과가 나온다. 민간 앱·연구에서 재사용 비용이 직접 줄어든다.

### 2. 상표·분류 명칭 체계 통일

**현황**
같은 알뜰주유소를 두 파일이 서로 다른 이름으로 부른다.

| 알뜰주유소 현황 파일 | 개수 | 일간 판매가격 파일 | 개수 |
|---|---|---|---|
| 농협알뜰 | 717 | NH-OIL | 720 |
| 자영알뜰 | 401 | 알뜰주유소 | 378 |
| 도로공사알뜰 | 210 | 알뜰(ex) | 205 |

상표별 평균판매가격 파일은 또 다른 체계다 — `알뜰주유소(전체)`, `알뜰(자영)`.

**문제**
"알뜰주유소가 몇 개인가"에 파일마다 다른 답이 나온다. 매핑표를 이용자가 직접 추측해서
만들어야 하고, 개수까지 어긋나 있어(717 vs 720) 매핑이 맞는지 검증할 방법도 없다.
오피넷 API 가이드의 상표코드 집합이 문서 안에서 불일치하는 것과 같은 뿌리의 문제다.

**제안**
상표·형태·알뜰구분에 **코드값과 명칭을 정의한 공통 코드집**을 만들어 개방하고,
모든 파일이 명칭 대신 코드값을 싣는다. 코드집에는 변경 이력을 함께 적는다.

**기대효과**
파일 간 결합이 추측 없이 가능해진다. 개수 불일치가 드러나 데이터 품질 점검도 자동화된다.

### 3. 가격 데이터를 시계열로 개방

**현황**
오피넷 계열 가격 파일은 대부분 **현재 시점 스냅샷**이다. 실제 행 수를 세어보면
- `주유소_평균판매가격_제품별` — 3행뿐(2026-09-17, 09-18, 전일대비)
- `주유소_형태별_평균판매가격` — **1일치**
- `주유소_상표별_평균판매가격` — 1시점
- LPG 9개 파일 — 전부 1시점 (`26년09월5주`)
- `전자상거래` — 1행
- `과거_판매가격(주유소)` — 10,251개 주유소 × **하루치**

반면 공공데이터포털 계열은 시계열이 있다. `요소수 지역별` 51개월(2022-04~2026-06),
`인천지역 휘발유` 12개월, `비축일수` 22년치.

**문제**
같은 기관 데이터인데 **가격만 추세를 볼 수 없다.** 그래서
"정유사 공급가가 오를 때와 내릴 때 주유소 가격 반영 속도가 다른가" 같은,
가격 데이터로 가장 하고 싶은 분석이 개방파일만으로는 **아예 불가능**하다.
매일 받아서 쌓는 수밖에 없는데, 그건 이용자에게 수집 부담을 떠넘기는 것이다.

**제안**
주유소·LPG·정유사 가격 파일을 **일자별 누적 시계열**로 개방한다(최소 3년).
전량이 부담이면 전국·지역·상표 단위 집계값만이라도 시계열로 내린다.
파일명에 이미 `20260918-20260918`처럼 기간이 들어가니, 기간 지정 다운로드를 열어주는
형태도 가능하다.

**기대효과**
가격 전가 시차·비대칭 분석, 정책 효과 검증, 지역 격차 추이 같은 연구가 그때부터 가능해진다.
현재는 연구자마다 수집기를 따로 돌려야 하므로 중복 비용이 크다.

### 4. 표 구조·기간·단위 표기 표준화

**현황**
한 기관 파일 안에서 표기 규칙이 제각각이다.
- **가로로 긴 표**: `국내 원유수입_국가별`은 49개국 × 3항목 = **148개 열**, 46개 행(1980~2025).
  국가별 데이터가 열로 펼쳐져 있어 **빈 칸이 3,351/6,762 = 49.6%**다. 절반이 빈칸인 표다.
  `인천지역 휘발유 가격`도 월이 열로 펼쳐진 형태(13열).
- **기간 표기 불일치**: LPG 집단공급사업자는 `2026년09월4주`, 충전소·판매소는 `26년09월5주`.
  같은 LPG 계열인데 연도가 4자리/2자리로 갈리고, 기준 주차도 다르다(4주 vs 5주).
- **단위 불일치**: 집단공급사업자는 `원/㎥`, 충전소·판매소는 `원/kg`. 3계층을 비교하려면
  이용자가 환산해야 한다.
- **회차 파일 묶임**: 「국내석유제품 가격 동향」 1개 목록에 월간·주간 PDF가 회차별로 섞여 있다.
  (우리도 이 때문에 확보 개수를 8건 부족으로 잘못 셌다 — 실제는 10건)

**문제**
기계가 읽기 어렵고, 파일을 합칠 때마다 사람이 규칙을 다시 알아내야 한다.
빈칸 49.6%짜리 표는 그대로는 분석 도구에 넣을 수 없다.

**제안**
개방 파일 작성 지침을 만들어 적용한다 — ① 국가·월처럼 값이 늘어나는 축은 열이 아니라
**행으로**(long/tidy 포맷) ② 기간은 `YYYY-MM-DD` 또는 `YYYY-Www` 한 가지로
③ 단위는 열 이름에 명시하고 같은 계열은 같은 단위로 ④ 회차 파일은 발행일·회차를
메타데이터로 노출.

**기대효과**
빈 칸 절반이 사라지고, 파일을 받아 바로 분석에 넣을 수 있다. 개수 집계 혼선도 없어진다.

### 5. 개방 CSV 인코딩을 UTF-8로 통일

**현황**
내려받은 CSV 73개의 인코딩이 **CP949 67개 / UTF-8(BOM) 6개**로 갈려 있다.
같은 기관이 같은 포털로 개방한 파일인데 기준이 둘이다.

**문제**
CP949는 UTF-8 환경(맥·리눅스·대부분의 분석 도구 기본값)에서 한글이 깨진다.
73개를 한 번에 읽는 코드를 짜면 파일마다 인코딩을 판별하는 코드를 먼저 넣어야 한다.
반대로 BOM 없는 UTF-8은 엑셀이 CP949로 오독한다.

**제안**
개방 CSV를 **UTF-8(BOM 포함)** 으로 통일한다. BOM을 넣는 이유는 엑셀 호환이다.
기존 파일은 일괄 변환해 재개방하고, 변환 전후 검증 결과를 함께 공개한다.

**기대효과**
실제로 해봤다 — 73개를 UTF-8(BOM)로 변환하고 **디코드한 문자열 동일 + 행·열 수 동일**을
검증해 **73/73 통과**했다(`evidence/encoding_convert_20260919.md`). 즉 데이터 손실 없이
가능한 작업이며, 이용자 쪽 전처리 코드가 통째로 사라진다.

### 6. 오피넷 API 제품코드·표기 정합성 확보

**현황**
오피넷 API 가이드(2026.06) 원문을 대조한 결과, 문서 내부가 어긋나 있다.
- 자동차부탄 제품코드가 **K015와 K105로 혼재** — K105는 p8·p9·p22·p23에만 쓰이고
  나머지 9개 API는 K015
- 이력: p2 변경내역에 2020.03.13 K015 제외 → 2024.09.23 K105 추가
- 엔드포인트 대소문자 불일치 — p22 요청 URL `datepollAvgRecentPrice.do` vs 예시
  `datePollAvgRecentPrice.do`
- 항목명 불일치 — p2 `GOOD_YN5` vs p13 `GOOD_YN_5`
- 상표코드 집합 불일치 — SKG·E1G가 p8·p22 계열에만 존재

**문제**
같은 제품을 부르는 코드가 API마다 달라, 여러 API를 엮는 개발자는 코드 분기를 넣어야 한다.
엔드포인트 대소문자는 서버 설정에 따라 **404를 내는 실제 장애 요인**이다.
문서만 보고 구현하면 어디서 틀렸는지 알 수 없다.

**제안**
① 자동차부탄 코드를 하나로 확정하고 과도기에는 양쪽을 모두 받되 가이드에 명시
② 가이드 배포 전 **엔드포인트·항목명·코드집합을 실제 API 응답과 자동 대조**하는 점검을 넣는다
③ 변경 이력에 "무엇이 왜 바뀌었는지"를 함께 적는다

**기대효과**
개발자가 가이드만 보고 한 번에 붙일 수 있다. 문서-구현 불일치로 생기는 문의·장애가 줄어든다.

### 7. LPG 유통 3계층 가격 투명성 지도

**현황**
LPG 가격이 유통 단계별로 따로 개방돼 있다. 같은 시점(26년09월5주) 값을 보면

| 단계 | 일반프로판 | 일반부탄 |
|---|---|---|
| 충전소 | 1,710.25 원/kg | 1,783.34 원/kg |
| 판매소 | 2,732.32 원/kg | 3,146.58 원/kg |
| 배수 | **1.60배** | **1.76배** |

집단공급사업자는 3,783.05 **원/㎥** 로 단위가 달라 바로 비교되지 않는다.

**문제**
소비자가 실제로 사는 곳은 판매소인데, 충전소보다 프로판 1.6배·부탄 1.76배다.
이 격차가 어디서 생기는지, 지역·회사별로 얼마나 다른지는 파일이 흩어져 있어 보이지 않는다.
단위까지 달라 3계층을 한 화면에 놓는 것 자체가 일이다.

**제안**
집단공급 → 충전소 → 판매소 3계층 가격을 **단위를 환산해 한 화면에** 놓고, 지역별(17개 시도)·
회사별로 단계별 격차를 지도와 표로 보여주는 서비스. "우리 지역 판매소가 전국 평균 대비
몇 % 비싼가"를 바로 답한다.

**기대효과**
프로판은 난방·취사 연료라 **도시가스 미보급 지역 가구**가 주 이용자다. 가격 격차가 드러나면
지역 소비자의 선택 근거가 되고, 지자체 LPG 지원 정책의 대상 선정에도 쓸 수 있다.

### 8. 주유소 가격차 요인 분해 — 상표·셀프·지역 중 무엇이 크나

**현황**
같은 날(2026-09-18) 보통휘발유 기준으로 세 요인의 크기를 각각 재보면

| 요인 | 차이 |
|---|---|
| 셀프 vs 비셀프 (전국) | **38.3원** |
| 알뜰(자영) vs 정유사상표(전체) | **35.8원** (1,824.03 vs 1,859.84) |
| 정유사 상표 간 (최고-최저) | 3.9원 (GS칼텍스 1,861.56 ~ HD현대오일뱅크 1,857.65) |

그런데 셀프/비셀프 차이는 **지역마다 크게 다르다** — 서울 127원, 인천 50원, 부산 41원인데
강원 27원, 충남 30원, 대구 30원. 서울이 강원의 **4.7배**다.
알뜰 안에서도 알뜰(자영) 1,824.03 vs 알뜰(전체) 1,849.38로 25원 차이가 난다.

**문제**
"알뜰주유소가 싸다"는 통념은 있지만, 알뜰 효과(35.8원)가 셀프 효과(38.3원)와 **거의 같다**는
사실은 드러나 있지 않다. 소비자가 실제로 아끼려면 무엇을 보고 골라야 하는지 알 수 없고,
정책 쪽에서도 알뜰 정책의 순효과를 분리해 평가하기 어렵다.

**제안**
상표·셀프여부·지역 세 요인을 분해해 **"이 가격차의 몇 원이 무엇 때문인가"** 를 보여주는
분석 서비스. 일간 판매가격 10,251개 개별 주유소 데이터에 상표·셀프여부가 함께 있으므로
개별 주유소 단위 비교가 가능하다.

**기대효과**
소비자는 자기 지역에서 무엇을 기준으로 골라야 절약되는지 알게 된다(서울은 셀프 여부가
127원, 강원은 27원 — 조언이 지역마다 달라야 한다). 알뜰 정책의 실효성을 정량 평가할 근거가
생긴다. ※ 단 현재는 하루치뿐이라 **개선 3번(시계열 개방)이 선행되어야** 추세 검증까지 간다.

### 9. 요소수 가격 지역 격차 모니터링

**현황**
요소수 지역별 평균판매가격은 **51개월(2022-04~2026-06)** 시계열이 개방돼 있다.
가장 최근 시점(2026-06-30) 지역 격차는

- 최고 **서울 2,058.24원** / 최저 **울산 1,447.07원**
- 격차 **611원, 1.42배**

**문제**
요소수는 경유 화물차에 반드시 필요한 소모품인데, 유가만큼 주목받지 않아
이 정도 지역 격차가 있다는 사실 자체가 알려져 있지 않다.
장거리 운행 화물차 운전자는 어느 지역에서 넣는 게 유리한지 모른 채 넣는다.

**제안**
요소수 가격을 **지역별·상표별로 추적하는 모니터링 보드**. 51개월 시계열이 있으므로
2021년 요소수 대란 이후 격차가 줄었는지 늘었는지 추세를 보여줄 수 있다.
주유소 위치 데이터와 엮으면 경로상 최저가 안내로도 확장된다.

**기대효과**
화물 운전자에게 직접적인 비용 절감 정보가 된다(1회 충전 10L 기준 지역 선택만으로 6,000원대
차이). 요소수 수급 불안이 재발할 때 **조기 경보 지표**로도 쓸 수 있다.

### 10. 에너지 안보 지표판 — 비축과 수입 집중도

**현황**
국내 석유 안보 관련 데이터가 여러 파일에 흩어져 있다.
- `국내 석유비축일수` — 2004년 **54일** → 2025년 **117일**, 정부비축량 74.2 → 100.6 백만배럴
- `국내 원유수입_국가별` — 1980~2025년, 49개국
- `국내 석유비축시설 및 비축물량`, `석유 정제가동율`, `정유사별 정제능력`
- 세계석유 5종(지역별·주요국별 매장량, 생산량, 소비량 추이, 일인당 소비량)

**문제**
"우리나라가 석유 공급이 끊기면 며칠 버티는가", "특정 국가 의존도가 얼마나 높은가"는
국민적 관심사인데, 답하려면 파일 5~6개를 직접 받아 엮어야 한다.
게다가 원유수입 파일은 148열 짜리라(개선 4번) 일반 이용자가 열기도 어렵다.

**제안**
비축일수·비축물량·수입국 집중도·정제능력을 한 화면에 모은 **에너지 안보 지표판**.
수입 집중도는 상위국 비중으로 지표화하고, 세계 생산·매장량과 나란히 놓아
"세계 공급에서 우리가 어디에 기대고 있는가"를 보여준다.

**기대효과**
에너지 안보를 숫자 하나(비축일수)로 계속 추적할 수 있게 된다. 22년치 시계열이 있어
정책 변화와 지표 변화를 연결해 볼 수 있고, 교육·언론에서 인용하기 쉬운 형태가 된다.
